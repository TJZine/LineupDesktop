# Choose your platform

Choose the Lineup build for the screen where you watch.
{ .lead }

Lineup is in pre-release. Windows and Android TV builds are for testers, and macOS is in private testing. Use only the official [GitHub Releases](https://github.com/TJZine/LineupDesktop/releases) assets when a public build is available, or a complete private package supplied by the maintainer.

## Before you start

- A Plex account and a reachable Plex Media Server with movie or TV libraries you can access.
- A connection to Plex sign-in and your server, directly or through an available remote or relay connection.

## Choose a build

| Platform | What you need |
| --- | --- |
| [Windows](windows.md) | Windows 10 or 11 on x64, a current GPU driver or Vulkan Runtime, and a complete portable ZIP. |
| [Android TV and Fire TV](android-tv.md) | Android 9 or later on ARM and an APK. This includes Google TV and Android-based Fire TV. |
| [macOS](macos.md) | Apple Silicon and macOS 14 Sonoma or later for private testing. |

See [Platform support](../reference/platforms.md) for testing status and other platforms. After installing, [set up your first lineup](first-lineup.md).
