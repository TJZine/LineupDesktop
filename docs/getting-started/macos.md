# macOS

The Mac version is in private testing.
{ .lead }

It needs Apple Silicon and macOS 14 Sonoma or later. Developers can build it from source by following [macOS runtime](https://github.com/TJZine/LineupDesktop/blob/main/docs/macos-runtime.md).
