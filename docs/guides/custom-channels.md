# Custom channels

Build, preview, and tune your own channel in Channel Studio.
{ .lead }

## Start a channel

In **Channels**, select **Add a custom channel**. Channel Studio also opens when you edit a custom channel or inspect a generated channel. Generated programming is read-only, but you can edit its name and number and choose **Save identity**.

Choose **Duplicate as custom** to start a separate draft from a generated channel without changing the original. Lineup gives the draft the lowest available channel number.

## Choose programs

Choose **Library** for a channel based on library filters or **Hand-picked** to put titles in an order you choose. Channels you made earlier from a Plex playlist or mixed sources keep working, and stay as they are until you change them.

In **Hand-picked**, use **Browse library** to search, filter, and select matching programs. You can select visible results together. Use **Channel programs** to reorder the list with the up and down arrow buttons. Counts remain visible, and your search and filters stay in place when you switch tabs.

A saved item missing from the current playable library shows **Unavailable — retained until removed**. Lineup keeps it in the list and leaves it out of the schedule until it can play it again.

## Preview the schedule

**Schedule preview** shows what's on now and next, how timing and the repeat cycle work, and why programs are included. Lineup's messages call this check Air Check. It uses the same scheduling rules as Guide and Player. It flags unavailable or invalid programming so you can fix it. See [How schedules work](schedules.md) for ordering and schedule stability.

## Save, tune, or delete

Choose **Save channel** when you have valid changes. After saving, **Tune in** becomes the main action. Save again after making another edit before you can tune. A failed tune leaves your channel saved. If you leave with unsaved changes, choose **Discard changes** or **Keep editing**.

Deletion requires confirmation and is permanent.

??? note "Details"
    A failed save keeps the previous lineup and the entire draft. Fix the source, schedule, channel number, or storage issue shown and try again.

    If the saved channel changes while Studio is open, choose **Use saved version…** or **Replace saved version with my draft…**. Both paths ask you to confirm. If the saved channel changes again before you finish, Lineup asks you to resolve the conflict again.
