# Desktop UI approved composition evidence

Archived September 8, 2026, unchanged from the synthetic design comparisons.
The [active specification](../../desktop-ui-design-spec.md) is authoritative for
behavior and later refinements. These fragments are not production UI or evidence
of Flutter, native playback, DPI, accessibility, performance or persistence correctness.

A/B labels belong to each comparison, not to a global design style. Where a file
contains alternatives, ONLY the direction named below is approved. An omitted
control does not cancel a spec requirement. Mock numeric counts, fake QR codes,
artwork and telemetry are illustrative. Do not turn local demonstration handlers
into application logic. No rejected full Guide Overlay comparison is included.

These are the original inline HTML fragments (local CSS/JS); the original
visualization host supplies presentation around them. They may be inspected in a
browser or rendered with the visualization skill's wrapper. No external account,
server, local HTTP service or real Plex data is needed for the synthetic examples.
No new visual design was produced in this archive pass.
