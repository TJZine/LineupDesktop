# Keyboard and remote

Use these shortcuts with a keyboard, media keys, or a TV remote.
{ .lead }

Media keys and remote buttons depend on what your device and operating system report to Lineup.

## Keyboard

| Context | Action | Keys |
| --- | --- | --- |
| Management screens | Move between controls | ++tab++ / ++shift+tab++ |
| Management screens | Activate the focused control | ++enter++ or ++space++ |

| Ready app | Open Settings | ++f3++ |
| Guide | Move between channels | ++arrow-up++ / ++arrow-down++ |

| Guide | Tune an airing program and open Player | ++enter++, ++num-enter++, ++space++, or Select |

Dedicated media Play, Pause, Stop, Rewind, and Fast Forward require **DVR playback controls** in Player. In Guide, Media Play jumps to the current time either way. For available actions and auto-hide timing, see [The Player](../guides/player.md) and [Settings](../guides/settings.md).

## Android TV and Fire TV remote

Use the D-pad to move focus and Select to activate the focused control. Back closes the current Player overlay, returns from Player to Guide, or follows the screen's Back action. In the root Guide, Back backgrounds Lineup without closing its task. Home belongs to the TV system.

Leaving Lineup or putting the TV to sleep stops playback and releases the player. If playback was active, returning tunes the channel at its current scheduled position. An explicit stop or an expired sleep timer keeps playback stopped. Restarting Lineup restores the saved profile, server, lineup, and channel through startup.

For text, first focus the field, then press Select to open the keyboard. Dismiss it or choose Done to move between fields again.

| Remote button | Action |
| --- | --- |
| Select | Show the compact controls when Player controls are hidden, or activate the focused control. |
| Left / Right | Move between Player actions. Seek with DVR controls enabled and the video focused. |
| Up / Down | With controls hidden, Up opens Mini Guide and Down shows the compact controls. From the compact action row, Down opens details when a program is available. In expanded details, move within the panel. |
| Channel Up / Channel Down | Tune the previous or next channel in Player. Move seven channels in Mini Guide or one visible page in Guide. |
| Guide | Open the full Guide from Player. In Guide browsing, return to Player. In the root Guide, open the Lineup menu. |
| Info | Expand Now Playing or collapse it to the compact controls. With no program, show the compact controls. |
| Menu | Open the Lineup menu from Player or Guide. |
| Play/Pause, Rewind, Fast Forward | Control playback with DVR controls enabled. |
| Number buttons | Enter a channel number in Player, then press Select to confirm. |

Guide and Info depend on the remote. Fire TV remotes provide Menu and may lack Guide or Info. From the first Guide row, Up moves to the nearest toolbar control. Down returns to the selected program cell. If playback fails, choose **Retry** when available or **Browse channels**.
