# Glossary

Look up terms you see in Lineup and in these guides.
{ .lead }

| Term | Definition |
| --- | --- |
| Lineup | The app. "A lineup" is your set of channels. |
| Lineup menu | The menu opened from **Open Lineup menu** on the Guide, Settings and Diagnostics, or **Lineup menu** on the Player. It leads to Guide, Player, Channels, Settings and Account. Player is available while a channel is loading, playing or paused, and when playback shows an error. **Now Playing** appears after tuning when the current program's details are available and playback has no error. |
| Guide | The program grid that shows what's on each channel now and for the next two to four hours, with the tuned channel playing in a picture-in-picture area. |
| Mini Guide | A short channel list over the Player, opened with Up, for changing channel without leaving the picture. |
| Player | The full view of the tuned channel. |
| OSD (on-screen controls) | The controls along the bottom of the Player: title, times, progress and actions. They hide after a few seconds. |
| Now Playing | The expanded on-screen controls, with synopsis, cast and what's on next. |
| Channel | A numbered schedule of programs from your Plex libraries that keeps playing whether or not you are watching. |
| Generated channel | A channel created by **Generate lineup**. Generating again can update or replace it. |
| Custom channel | A channel you build in Channel Studio. Generating a lineup never changes it. |
| Channel Studio | The page for building or editing a custom channel and inspecting a generated one. |
| Air Check | The Channel Studio preview of what a channel plays now and next, and why. |
| Hand-picked | Custom channel programming made of titles you choose and order yourself. |
| Playback order | How a channel orders its programs: **Shuffle**, **In order** or **Mini-marathons** (blocks of 2 to 5 episodes of one show). |
| PiP | Picture-in-picture: the video area in the Guide that keeps playing the tuned channel. |
| DVR playback controls | An optional setting that adds pause, seek and media-key controls to the Player. |
| Direct Play | Lineup plays the file as stored on your server, so your device must be able to play its format. |
| Plex Home profile | A user in your Plex Home. After you link Plex, Lineup asks which profile to use if Plex returns more than one. |
| Plex Media Server | The server that holds your movie and TV libraries. |
| Support report | A redacted summary of recent diagnostic events that you can copy from Diagnostics when asking for help. Review it before sharing. |
