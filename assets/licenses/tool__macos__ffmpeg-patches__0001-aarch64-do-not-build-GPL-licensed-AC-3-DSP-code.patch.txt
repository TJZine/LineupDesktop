Lineup Desktop: do not build the GPL-licensed aarch64 AC-3 DSP code.

libavcodec/aarch64/ac3dsp_init_aarch64.c and ac3dsp_neon.S carry GPL-2.0+
headers (in FFmpeg 9.0.2 and in FFmpeg master), unlike the rest of this LGPL
build. The AC-3 DSP functions they accelerate fall back to the portable C
versions in libavcodec/ac3dsp.c; AC-3/E-AC-3 decoding is unchanged.
