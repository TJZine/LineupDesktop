Lineup Desktop: do not build the GPL-licensed aarch64 CRC assembly.

libavutil/aarch64/crc.S carries a GPL-2.0+ header (in FFmpeg 9.0.2 and in
FFmpeg master). The build also passes --disable-arm-crc --disable-pmull
--disable-eor3, so libavutil/aarch64/crc.h (LGPL) never references it and
libavutil uses its portable C CRC code.
